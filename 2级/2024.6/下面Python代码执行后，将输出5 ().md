# 🐍 Python 基础知识：双重循环中的步长与条件计数

在 Python 的嵌套循环中，`range(start, stop, step)` 的步长参数 `step` 决定了内层循环的跳跃间隔。同时，`if` 条件判断决定了最终 `cnt` 的累加次数。

---

## 📝 题目回顾

**24、下面 Python 代码执行后，将输出 5。（）**

```python
cnt = 0
for i in range(1, 5):
    for j in range(i, 5, i):
        if i * j % 2 == 0:
            cnt += 1
print(cnt)
```

* **正确 (√)**
* 错误

**解析**：
* **你的答案**：错误
* **正确答案**：正确

---

## 🔍 核心考点深度拆解

### 1. `range` 函数的动态范围与步长
* 外层循环 `i` 的取值为：`1, 2, 3, 4`。
* 内层循环 `j` 的范围是 `range(i, 5, i)`，这意味着起始位置和**步长**都随 `i` 的变化而变化。

### 2. 逐层逻辑推演
我们需要计算满足 `i * j % 2 == 0`（即 `i * j` 为偶数）的次数：

| 外层 `i` | 内层 `range(i, 5, i)` | `j` 的取值 | `i * j` 的结果 | 是否为偶数 (cnt+1) |
| :--- | :--- | :--- | :--- | :--- |
| **1** | `range(1, 5, 1)` | 1, 2, 3, 4 | 1, **2**, 3, **4** | **2 次** |
| **2** | `range(2, 5, 2)` | 2, 4 | **4**, **8** | **2 次** (2是偶数，结果必偶) |
| **3** | `range(3, 5, 3)` | 3 | 9 | 0 次 |
| **4** | `range(4, 5, 4)` | 4 | **16** | **1次** (4是偶数，结果必偶) |



### 3. 汇总计算
* `i = 1` 时：`cnt` 增加 2 次。
* `i = 2` 时：`cnt` 增加 2 次。
* `i = 3` 时：`cnt` 增加 0 次。
* `i = 4` 时：`cnt` 增加 1 次。
* **总计**：`2 + 2 + 0 + 1 = 5`。

---

## ❌ 错因分析

你可能在分析时忽略了以下细节：
1. **步长 `i` 的影响**：当 `i=2` 时，步长也是 `2`，所以 `j` 只能取 `2` 和 `4`。
2. **偶数判定逻辑**：只要 `i` 或 `j` 其中一个是偶数，它们的乘积 `i * j` 就一定是偶数。
    * 当 `i=2` 或 `i=4` 时，内层循环只要能跑起来，每一次都会让 `cnt` 加 1。
3. **边界值**：`range(start, 5)` 不包含 `5`，所以 `j` 最大只能到 `4`。

---

## 💡 知识拓展：步长参数的妙用

在 `range(start, stop, step)` 中：
* 如果省略 `step`，默认是 `1`。
* 如果 `step` 与 `start` 相同，例如 `range(i, stop, i)`，产生的序列本质上是 **`i` 的倍数**（如 `i, 2i, 3i...`）。这种结构常用于寻找约数、倍数或筛选素数（如埃拉托斯特尼筛法）。
