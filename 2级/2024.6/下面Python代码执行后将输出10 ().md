# 🐍 Python 基础知识：循环起点与 break 语句的执行时机

在 Python 的嵌套循环中，内层循环是否执行，取决于 `range()` 函数产生的序列是否为空。如果内层循环不启动，其内部的所有语句（包括累加和 `break`）都不会被执行。

---

## 📝 题目回顾

**23、下面 Python 代码执行后将输出 10。（）**

```python
cnt = 0
for i in range(10):
    for j in range(i):
        cnt += 1
        break
print(cnt)
```

* 正确
* **错误 (√)**

**解析**：
* **你的答案**：正确
* **正确答案**：错误（实际输出为 9）

---

## 🔍 核心考点深度拆解

### 1. `range(i)` 的动态变化
外层循环 `i` 的取值范围是 `0, 1, 2, ..., 9`。
内层循环 `range(i)` 的表现如下：
* **当 `i = 0` 时**：`range(0)` 是一个空序列。内层 `j` 循环**一次都不会执行**。
    * 结果：`cnt` 保持为 0。
* **当 `i = 1` 时**：`range(1)` 产生 `[0]`。内层循环执行 1 次。
    * 结果：`cnt` 变为 1，随即遇到 `break` 跳出内层。
* **当 `i = 2` 时**：`range(2)` 产生 `[0, 1]`。但由于 `break` 的存在，内层依然只执行 1 次。
    * 结果：`cnt` 变为 2。

### 2. 执行次数统计表

| 外层 `i` 的值 | 内层 `range(i)` 是否执行 | `cnt` 累加情况 |
| :--- | :--- | :--- |
| 0 | 否 (空序列) | 不变 (0) |
| 1 | 是 (执行 1 次) | 0 + 1 = 1 |
| 2 | 是 (执行 1 次后 break) | 1 + 1 = 2 |
| ... | ... | ... |
| 9 | 是 (执行 1 次后 break) | 8 + 1 = 9 |



### 3. `break` 的位置
在本题中，`cnt += 1` 位于 `break` 之前且都在内层循环中。这意味着：
* 只要内层循环能进去，`cnt` 就会加 1。
* 只要加了 1，立刻就会 `break`。
* 所以每轮外层循环，`cnt` 最多只能加 1。

---

## ❌ 错因分析

你可能产生了以下思维定势：
1. **忽略了 `i=0` 的特殊性**：习惯性地认为外层循环跑 10 次，内层就会贡献 10 次计数。但 Python 的 `range(0)` 是不工作的。
2. **混淆了本题与第 10 题的区别**：
    * **第 10 题**：`cnt += 1` 在外层，不受内层空循环影响。
    * **本题**：`cnt += 1` 在内层，必须内层转动才能加分。

---

## 💡 知识拓展：如何让它输出 10？

如果想让这段代码输出 10，有几种修改方案：
1. **改变内层起点**：将内层改为 `for j in range(i + 1):`。这样当 `i=0` 时，内层是 `range(1)`，会执行一次。
2. **改变变量归属**：将 `cnt += 1` 的缩进向左移动一格（移出内层循环），使其属于外层循环。

---

## 📅 避坑指南：边界值检查

* **“零”陷阱**：看到 `range(i)` 这种变量范围，第一反应应该是检查当 `i=0` 时会发生什么。
* **流程追踪**：对于这种循环次数不多的题，手动模拟前两次（`i=0, i=1`）和最后一次（`i=9`）通常就能锁定正确答案。

---

> **结论**：内层循环的开启是 `cnt` 增加的前提。由于 `i=0` 时内层循环是“哑火”状态，导致总次数比外层循环次数少 1。
