# 🐍 Python 基础知识：循环控制语句与 else 子句

在 Python 的 `for` 循环中，`continue` 语句用于跳过当前迭代的剩余代码，而 `else` 子句则具有非常独特的触发机制。理解这两者的交互是解决本题的关键。

---

## 📝 题目回顾

**8、下面 Python 代码执行后输出是？（ ）**

```python
for i in range(10):
    if i % 3 == 0:
        continue
    print("0", end="#")
else:
    print("1", end="#")
```

* A. 0#0#0#0#0#0#
* B. 0#0#0#0#0#0#0#1#
* C. 0#0#0#0#1#
* D. **0#0#0#0#0#0#1# (√)**

**解析**：
* **你的答案**：A
* **正确答案**：D

---

## 🔍 核心考点深度拆解

### 1. `continue` 的作用
`continue` 语句会立即结束当前这一轮循环，直接进入下一轮迭代。
* 在本题中，当 `i` 是 3 的倍数（`0, 3, 6, 9`）时，`if i % 3 == 0` 成立，执行 `continue`。
* 此时，程序会跳过后面的 `print("0", end="#")`，直接进行下一次 `i` 的赋值。

### 2. `for...else` 结构的触发条件
这是 Python 的一个高级特性：
* **如果 `for` 循环正常执行完毕**（即不是通过 `break` 强行终止的），那么循环结束后**必然会执行** `else` 块中的代码。
* `continue` 并不影响循环的“正常结束”，它只是跳过某些步骤，所以 `else` 部分仍会运行。



### 3. 执行轨迹追踪 (`range(10)` 为 0~9)

| i 的值 | i % 3 == 0 | 执行动作 | 输出内容 |
| :--- | :--- | :--- | :--- |
| **0** | 是 | `continue` | (跳过) |
| **1** | 否 | `print("0")` | `0#` |
| **2** | 否 | `print("0")` | `0#` |
| **3** | 是 | `continue` | (跳过) |
| **4** | 否 | `print("0")` | `0#` |
| **5** | 否 | `print("0")` | `0#` |
| **6** | 是 | `continue` | (跳过) |
| **7** | 否 | `print("0")` | `0#` |
| **8** | 否 | `print("0")` | `0#` |
| **9** | 是 | `continue` | (跳过) |
| **结束** | - | **执行 else** | `1#` |

**最终拼接结果**：`0#0#0#0#0#0#1#`

---

## ❌ 错因分析

1. **忽视了 `else` 块**：你可能认为 `else` 只与 `if` 配对。但在 Python 中，`else` 可以写在 `for` 循环的正下方。只要循环没被 `break` 掉，最后那个 `1#` 是一定会出来的。
2. **循环范围计算**：`range(10)` 中非 3 倍数的数字共有 6 个（1, 2, 4, 5, 7, 8），所以对应输出了 6 个 `0#`。

---

## 💡 知识拓展：`break` vs `continue` 在 `else` 中的区别

* **使用 `continue`**：循环最终会数完所有数字，`else` 会执行。
* **使用 `break`**：循环被中途暴力切断，`else` **不会**执行。这通常用于“在列表中寻找某物，找到就停止，没找到则执行 else”。

---

## 📅 避坑指南：快速判定

* **数 `0#` 的个数**：`range(10)` 有 10 个数。3 的倍数（含 0）有 4 个（0, 3, 6, 9）。输出 `0#` 的次数 = $10 - 4 = 6$ 次。
* **尾巴判定**：看到没有 `break` 的 `for...else`，结果最后一定带着 `else` 里的输出。

---

> **结论**：本题考查 `continue` 跳过指定逻辑以及 `for...else` 正常结束必执行的特性。
