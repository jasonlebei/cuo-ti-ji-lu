# 🐍 Python 基础知识：日期时间进位逻辑深度解析

“时间跨越”问题在编程竞赛中属于**模拟类题目**。它不需要复杂的算法，但要求逻辑极其严密。我们需要像时钟齿轮一样，处理好**小时 $\rightarrow$ 天 $\rightarrow$ 月 $\rightarrow$ 年**的链式反应。

---
## 📝 题目描述

**27、时间跨越**
* **时间限制**：1.0s
* **内存限制**：512.0MB

### 【问题描述】
假设现在是 $y$ 年 $m$ 月 $d$ 日 $h$ 时，而 $k$ 小时后是 $y'$ 年 $m'$ 月 $d'$ 日 $h'$ 时。对于给定的 $y$、$m$、$d$、$h$、$k$，小杨想请你帮他计算出对应的 $y'$、$m'$、$d'$、$h'$ 是多少。

### 【输入描述】
输入包含五行，每行一个正整数，分别代表 $y$、$m$、$d$、$h$、$k$。

### 【输出描述】
输出四个正整数，每行一个，分别代表 $y'$、$m'$、$d'$、$h'$。

### 【样例输入 1】
```text
2008
2
28
23
1
```

### 【样例输出 1】
```text
2008
2
29
0
```

### 【数据范围】
对于全部数据，保证有：
* $2000 \le y \le 3000$
* $1 \le m \le 12$
* $1 \le d \le 31$
* $0 \le h \le 23$
* $1 \le k \le 24$
* 数据保证输入为合法时间。

### 【提示】闰年判断规则
1.  **普通闰年**：年份能被 4 整除，但不能被 100 整除。
2.  **世纪闰年**：年份能被 400 整除。
满足以上任意一条规则的年份就是闰年，否则是平年。
---

## 🔍 第一步：核心逻辑链条（分层进位）

处理时间跨越最稳妥的方法是**从最小单位开始计算，逐级向上检查是否需要进位**。

### 1. 小时的进位逻辑
由于题目给定 $1 \le k \le 24$，当前小时 $h$ 加上 $k$ 后，可能会超过或等于 24 小时。
* **计算方法**：$h = h + k$。
* **进位判定**：如果 $h \ge 24$，说明跨天了。此时 $h$ 需要减去 24，同时日期 $d$ 增加 1。



### 2. 天数的进位逻辑（最难点）
日期 $d$ 增加后，可能会超过当前月份的最大天数。
* **关键点**：每个月的天数是不固定的（28, 29, 30 或 31 天）。
* **进位判定**：如果 $d >$ 当前月份的天数，说明跨月了。此时日期 $d$ 重置为 1，同时月份 $m$ 增加 1。



### 3. 月份与年份的进位
* **进位判定**：如果月份 $m$ 超过了 12，说明跨年了。此时月份 $m$ 重置为 1，年份 $y$ 增加 1。

---

## 🛠️ 第二步：如何准确判断“当前月天数”？

这是程序能否运行正确的基石。我们需要处理**普通月**和**闰年 2 月**。

### 1. 闰年判断规则
根据提示，我们需要写一个逻辑判断：
* 能被 4 整除 **且** 不能被 100 整除（如 2004, 2008）。
* **或者** 能被 400 整除（如 2000, 2400）。



### 2. 构建天数查找表
在 Python 中，使用列表（List）来存储 1-12 月的天数是最直观的：
```python
# 索引 0 占位，使月份与索引对应：1月对应 month_days[1]
month_days = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

# 如果是闰年，手动将 2 月修改为 29 天
if (y % 4 == 0 and y % 100 != 0) or (y % 400 == 0):
    month_days[2] = 29
```

---

## ✍️ 第三步：分步执行解析（以样例为例）

输入：`y=2008, m=2, d=28, h=23, k=1`

1.  **小时处理**：
    * $h = 23 + 1 = 24$。
    * 触发条件 $h \ge 24$，所以 $h = 24 - 24 = 0$，日期 $d$ 变为 $28 + 1 = 29$。
2.  **获取当月上限**：
    * 2008 是闰年，`month_days[2]` 为 29。
3.  **日期处理**：
    * 此时 $d = 29$。检查 $d > month\_days[2]$ 吗？
    * $29 > 29$ 不成立（正好是该月最后一天，没跨月）。
4.  **输出结果**：
    * `2008 2 29 0`

## 💡 代码实现要点

```python
import sys

# 读取输入
y = int(input())
m = int(input())
d = int(input())
h = int(input())
k = int(input())

# 1. 先加小时
h += k
if h >= 24:
    h -= 24
    d += 1 # 进位到天

# 2. 确定该年该月有多少天
# 定义平年天数
days_in_month = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
# 判断闰年
if (y % 400 == 0) or (y % 4 == 0 and y % 100 != 0):
    days_in_month[2] = 29

# 3. 处理日期进位
if d > days_in_month[m]:
    d = 1
    m += 1 # 进位到月

# 4. 处理月份进位
if m > 12:
    m = 1
    y += 1 # 进位到年

# 按照题目要求输出
print(y)
print(m)
print(d)
print(h)
```

## 📅 避坑指南：为什么我的代码会错？

* **顺序错误**：必须先算小时，再算日期，最后算月份。如果先判断日期是否超限再加小时，就会漏掉由小时带来的进位。
* **忽略 $h=24$**：小时是从 0 到 23 的，当结果刚好是 24 时，它必须变成 0 并进位。
* **闰年逻辑**：注意 `and` 和 `or` 的优先级，或者直接加括号。

---

> **结论**：模拟题的关键在于**状态更新的顺序**。只要保证每一级进位都正确触发，无论时间跨度多大都能准确计算。
