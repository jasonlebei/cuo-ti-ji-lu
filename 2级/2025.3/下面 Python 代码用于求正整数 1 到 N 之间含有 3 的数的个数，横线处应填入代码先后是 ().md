# 🐍 Python 基础知识：循环嵌套与数字位数拆解逻辑

在处理“判断数字中是否包含特定位（如 3）”的问题时，通常采用“取余（%）获取末位”与“整除（//）去掉末位”的组合拳。同时，合理的循环控制语句能有效提升代码效率并避免重复计数。

---

## 📝 题目回顾

**11、下面 Python 代码用于求正整数 1 到 N 之间含有 3 的数的个数，横线处应填入代码先后是？（ ）**

```python
cnt = 0
N = int(input("请输入正整数："))
for i in range(1, N): # 遍历 1 到 N-1
    while i != 0:
        if i % 10 == 3:
            cnt += 1      # 原题识别可能有误，此处应为累加
            _________     # 横线 1：找到一个 3 即可跳出当前数字的检查
        else:
            _________     # 横线 2：当前位不是 3，去掉末位继续检查
print(cnt)
```

* A. `i //= 10`, `break`
* B. **`break`, `i //= 10` (√)**
* C. `i %= 10`, `break`
* D. `i %= 10`

**解析**：
* **你的答案**：D
* **正确答案**：B

---

## 🔍 核心考点深度拆解

### 1. 数字位数的逐位检查法
要检查一个数（如 135）是否包含数字 3，逻辑如下：
1.  **取末位**：用 `i % 10`。$135 \pmod{10} = 5$，不是 3。
2.  **去末位**：用 `i //= 10`（整除）。$135 // 10 = 13$。
3.  **重复执行**：
    * $13 \pmod{10} = 3$，**是 3！** 计数器 `cnt + 1`。
    * **关键点**：此时已经确定 135 包含 3，不需要再查百位的 1 了。



### 2. 控制语句的选择逻辑
* **横线 1 为 `break`**：
  一旦通过 `if i % 10 == 3` 找到了数字 3，该整数就符合条件。此时必须使用 `break` 立即跳出内层的 `while` 循环。如果不跳出，像 `33` 这种数字会被重复计数（个位计一次，十位计一次），导致结果错误。
* **横线 2 为 `i //= 10`**：
  如果当前末位不是 3（进入 `else` 分支），则需要去掉末位，让数字“变短”，从而在下一轮 `while` 循环中检查更高的一位。

---

## ❌ 错因分析

1.  **混淆取余与整除**：你选择的 `i %= 10` 是保留余数（如 135 变成 5），这会直接丢失掉十位和百位的信息，无法完成“逐位检查”。
2.  **忽略“找到即停止”**：如果没有 `break`，`while i != 0` 会在找到 3 后继续运行，不仅浪费计算资源，还会导致逻辑错误。

---

## 💡 知识拓展：代码的潜在风险

在实际编程中，直接在 `for` 循环内部修改循环变量 `i`（即 `i //= 10`）是非常危险的：
* 在 Python 中，`for i in range()` 每一轮开始都会重新给 `i` 赋值，虽然不会导致死循环，但会使内层 `while` 的逻辑变得难以追踪。
* **更规范的写法**：先用一个临时变量备份 `i`，如 `temp = i`，然后对 `temp` 进行拆解。

---

## 📅 避坑指南：快速判定

* **“含有什么数”**：联想 `while` 循环里的 `% 10`（取位）和 `// 10`（降位）。
* **“找到一个就够”**：联想 `break` 提高效率并防止重复。
* **运算符区分**：
    * `/`：除法（结果是浮点数，如 `5 / 2 = 2.5`）
    * `//`：整除（结果是整数，去末位必用，如 `5 // 2 = 2`）
    * `%`：取余（取末位必用，如 `5 % 2 = 1`）

---

> **结论**：本题考查的是经典的**逐位拆解算法**。核心逻辑是：**匹配则跳出 (break)，不匹配则降位 (//= 10)**。
