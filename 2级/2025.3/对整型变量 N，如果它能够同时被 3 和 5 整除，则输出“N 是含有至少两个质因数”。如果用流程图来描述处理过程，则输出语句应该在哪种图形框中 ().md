# 💾 计算机基础知识：流程图基本符号与逻辑判断

在算法设计中，流程图（Flowchart）是一种直观展示程序逻辑的工具。每一个图形符号都承载着特定的功能，规范化的符号能确保逻辑表达的准确性。

---

## 📝 题目回顾

**2、对整型变量 N，如果它能够同时被 3 和 5 整除，则输出“N 是含有至少两个质因数”。如果用流程图来描述处理过程，则输出语句应该在哪种图形框中？**

* A. 圆形框
* B. 椭圆形框
* C. **平行四边形框 (√)**
* D. 菱形框

**解析**：
* **你的答案**：B（椭圆形框）
* **正确答案**：C（平行四边形框）

---

## 🔍 核心考点深度拆解

### 1. 流程图标准符号及其含义

为了确保算法逻辑的通用性，标准流程图符号规定如下：



| 图形 | 名称 | 功能说明 | 常见场景 |
| :--- | :--- | :--- | :--- |
| **椭圆形 (Oval)** | 起止框 | 表示算法的**开始**或**结束** | 程序 Start / End |
| **平行四边形 (Parallelogram)** | 输入/输出框 | 表示**数据的输入**或**结果的展示** | **print("结果")**、input(N) |
| **矩形 (Rectangle)** | 处理框 | 表示具体的**算术运算**、赋值或操作 | $N = N + 1$ |
| **菱形 (Diamond)** | 判断框 | 表示**逻辑判断**，根据条件真假分流 | $N \pmod{15} == 0 ?$ |

### 2. 本题逻辑映射
题目中提到的关键动作是“**输出**...”，这在计算机程序设计中属于典型的**数据输出（Output）**行为。
* **椭圆形框**（你选的 B）：仅用于程序的起点或终点，不承载具体的业务逻辑。
* **菱形框**：用于“如果 $N$ 能被 3 和 5 整除”这个条件的**判断**过程。
* **平行四边形框**：承接判断后的结果，负责将信息**输出**给用户。

## 💡 知识拓展：质因数与逻辑实现

虽然本题侧重框图，但背后的 Python 逻辑如下：

```python
# 逻辑判断 (对应菱形框)
if N % 3 == 0 and N % 5 == 0:
    # 输出操作 (对应平行四边形框)
    print("N是含有至少两个质因数")
```

**数学原理**：3 和 5 均为质数。若 $N$ 能被 $15$ 整除，根据算术基本定理，$N$ 的质因数分解式中至少包含 $3$ 和 $5$ 这两个不同的质数。

## 📅 避坑指南：快速记忆法

* **“平行”出入**：看到“输入”、“输出”、“获取”、“打印”，认准有斜边的**平行四边形**。
* **“菱”里寻他**：看到“如果”、“是否”、“大于/小于”，认准**菱形**（通常有两个分支：Yes/No）。
* **“圆”满结束**：看到程序的“头”和“尾”，认准**椭圆/圆角矩形**。

---

> **结论**：在流程图中，所有涉及数据交换（Input/Output）的操作，必须使用**平行四边形**
