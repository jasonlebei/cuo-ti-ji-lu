# 🐍 Python 基础知识：循环结构与取余逻辑判定

在 Python 编程中，`for` 循环与 `if` 条件判断的组合是处理数据的核心逻辑。准确追踪循环变量 `i` 的变化以及条件的触发点是解题的关键。

---

## 📝 题目回顾

**6、下面 Python 代码执行后其输出是？（ ）**

```python
tnt = 0
for i in range(10):
    if i % 3:
        tnt += 1
    else:
        tnt += 2
print(tnt)
```

* A. 18
* B. 17
* C. 16
* D. **14 (√)**

**解析**：
* **你的答案**：B (17)
* **正确答案**：D (14)

---

## 🔍 核心考点深度拆解

### 1. `if i % 3` 的隐式布尔判断
在 Python 的 `if` 语句中，数值会进行隐式类型转换：
* **非零整数**（1, 2...） $\rightarrow$ `True`
* **整数零**（0） $\rightarrow$ `False`

因此，`if i % 3:` 的实际含义是：**“如果 i 除以 3 的余数不为 0（即不能被 3 整除）”**。



### 2. 循环追踪过程（range(10) 生成 0 到 9）

| 循环轮次 `i` | `i % 3` 结果 | 判断结果 | 执行分支 | `tnt` 累加过程 |
| :--- | :--- | :--- | :--- | :--- |
| **0** | 0 | **False** | `else: +2` | 2 |
| **1** | 1 | **True** | `if: +1` | 3 |
| **2** | 2 | **True** | `if: +1` | 4 |
| **3** | 0 | **False** | `else: +2` | 6 |
| **4** | 1 | **True** | `if: +1` | 7 |
| **5** | 2 | **True** | `if: +1` | 8 |
| **6** | 0 | **False** | `else: +2` | 10 |
| **7** | 1 | **True** | `if: +1` | 11 |
| **8** | 2 | **True** | `if: +1` | 12 |
| **9** | 0 | **False** | `else: +2` | **14** |

---

## ❌ 错因分析

1. **`i = 0` 的处理**：很多同学会漏掉 0 或者认为 0 不能被 3 整除。实际上 `0 % 3` 结果为 `0`，在 `if` 判断中为 `False`，所以执行了 `else` 分支的 `+2`。
2. **逻辑方向**：容易下意识地把 `if i % 3` 当成“能整除”，导致 `+1` 和 `+2` 的对象搞反。

---

## 💡 知识拓展：分组快速计算法

对于此类有规律的循环，可以统计次数来快速求和：
* **符合 `else` 条件（能被 3 整除）的数**：`0, 3, 6, 9`（共 4 个）。
  * 贡献值：$4 \times 2 = 8$
* **符合 `if` 条件（不能被 3 整除）的数**：`1, 2, 4, 5, 7, 8`（共 6 个）。
  * 贡献值：$6 \times 1 = 6$
* **最终结果**：$8 + 6 = 14$

---

## 📅 避坑指南：range 与取余

* **`range(start, end)`**：包含 `start`，但不包含 `end`。`range(10)` 的最后一个数是 9。
* **布尔真值表**：牢记 `0`, `None`, `[]`, `""`, `{}` 在 `if` 判断中皆为假。

---

> **结论**：本题的关键在于理解 `if i % 3` 筛选的是“余数不为零”的数字，并正确处理 `i = 0` 这一轮循环。
