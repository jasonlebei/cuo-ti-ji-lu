# 🐍 Python 基础知识：双重循环实现等腰三角形逻辑

在 Python 中使用嵌套循环打印图形时，核心在于建立 **当前行号 `i`** 与 **空格数量** 及 **星号数量** 之间的数学映射关系。

---

## 📝 题目回顾

**15、下面 Python 代码实现输出等腰三角形（高度为 5），横线应填入的代码是？**

```python
height = int(input("高度："))
for i in range(height):
    # 打印每行前面的空格
    for j in range(________):  # 空格循环
        print(" ", end="")
    # 打印每行的星号
    for k in range(________):  # 星号循环
        print("*", end="")
    print() # 换行
```

* A. `height - i` | `2 * i`
* B. `height` | `2 * i`
* C. `height - i` | `2 * i + 1`
* D. **`height - i - 1` | `2 * i + 1` (√)**

**解析**：
* **你的答案**：A
* **正确答案**：D

---

## 🔍 核心考点深度拆解

假设 `height = 5`，我们观察每一行 `i`（从 0 开始）的变化规律：

| 行号 `i` | 空格数 (j 循环) | 星号数 (k 循环) | 图形样子 |
| :--- | :--- | :--- | :--- |
| **0** | 4 | 1 | `    *` |
| **1** | 3 | 3 | `   ***` |
| **2** | 2 | 5 | `  *****` |
| **3** | 1 | 7 | ` *******` |
| **4** | 0 | 9 | `*********` |

### 1. 找寻空格规律（第一个空）
观察表格中的空格数：4, 3, 2, 1, 0。
* 当 `i=0` 时，空格 = 4 (即 $5 - 0 - 1$)
* 当 `i=1` 时，空格 = 3 (即 $5 - 1 - 1$)
* **通项公式**：$\text{height} - i - 1$。
* **为什么 A 不对？** 如果填 `height - i`，第一行（`i=0`）会打印 5 个空格，导致星号整体右移一位，且最后一行（`i=4`）会多出一个空格。



### 2. 找寻星号规律（第二个空）
观察表格中的星号数：1, 3, 5, 7, 9。
这是一个公差为 2 的等差数列。
* 当 `i=0` 时，星号 = 1 (即 $2 \times 0 + 1$)
* 当 `i=1` 时，星号 = 3 (即 $2 \times 1 + 1$)
* **通项公式**：$2 \times i + 1$。
* **注意**：等腰三角形的每一行星号数永远是**奇数**。

---

## ❌ 错因分析
你选择 A 可能由于以下疏忽：
1.  **索引对齐问题**：忘记了 `range(height)` 是从 `0` 开始的。当 `i=0` 时，如果不减 1，第一行的空格数就等于高度，这会使图形失去对齐美感。
2.  **奇偶性忽略**：`2 * i` 产生的是偶数序列（0, 2, 4...），而等腰三角形的尖端通常只有一个 `*`（即 1 个，奇数）。

## 💡 知识拓展：Python 字符串乘法的快捷方式

在实际开发中，我们很少用嵌套循环去打印这种简单图形，Python 支持更简洁的写法：

```python
for i in range(height):
    spaces = " " * (height - i - 1)
    stars = "*" * (2 * i + 1)
    print(spaces + stars)
```
这种方式直接利用字符串的乘法特性，逻辑更加清晰。

## 📅 避坑指南：图形题套路

* **先列坐标表**：不要在脑子里硬想，像我上面那样列个 `i` 与数量的关系表，规律一眼便知。
* **首尾验证**：代入 `i=0`（第一行）和 `i=height-1`（最后一行）进行检查。
    * 最后一行通常空格为 0。代入 D 选项：$5 - 4 - 1 = 0$，正确！

---

> **结论**：空格负责把星号“顶”到中间，数量随 `i` 递减；星号负责撑起宽度，数量随 `i` 以 $2i+1$ 递增。
