# 🐍 Python 基础知识：循环边界控制与逻辑约束

在处理序列或范围问题时，`range()` 函数的停止参数（Stop Argument）不仅决定了循环的次数，还必须确保循环体内部的所有索引或计算（如 `i + 2`）不会越出题目要求的边界。

---

## 📝 题目回顾

**14、输出 N 和 M 之间的孪生素数（包含 N 和 M），且孪生素数都在 N 和 M 之间。**
（孪生素数：间隔为 2 的两个数均为素数，如 11 和 13）

```python
N = int(input())
M = int(input())
for i in range(N, ________):
    if isPrime(i) and isPrime(i + 2):
        print(i, i + 2)
```

* A. `M - 2`
* B. **`M - 1` (√)**
* C. `M`
* D. `M + 1`

**解析**：
* **你的答案**：D
* **正确答案**：B

---

## 🔍 核心考点深度拆解

### 1. 隐含的边界不等式
题目要求“孪生素数都在 N 和 M 之间”，这意味着对于每一对输出的 `(i, i + 2)`，必须满足：
1.  $i \ge N$ （循环起点 `range(N, ...)` 已经保证了这一点）
2.  **$i + 2 \le M$** （这是关键约束：较大的那个素数不能超过 M）

我们根据第二个约束条件推导 $i$ 的取值范围：
$$i + 2 \le M \implies i \le M - 2$$

### 2. `range()` 函数的特性
在 Python 中，`range(start, stop)` 产生的序列是 $[start, stop)$，即**包含起点，不包含终点**。
* 如果我们要让 $i$ 的最大取值达到 $M - 2$：
* 那么 `range` 的第二个参数（stop）必须是 **$M - 2 + 1$**。
* 计算结果：$M - 1$。



### 3. 带入验证
* 如果填 **`M - 1`**：`i` 最大取到 `M - 2`，此时 `i + 2` 最大为 `(M - 2) + 2 = M`。符合“包含 M”的边界要求。
* 如果填 **`M + 1`**（你的选项）：`i` 最大能取到 `M`，此时 `i + 2` 就会变成 `M + 2`。这超出了题目要求的范围 $[N, M]$。

---

## ❌ 错因分析
你选择 D (M+1) 可能是受到了常规思维的干扰：
* **惯性思维**：通常题目说“包含 M”，我们会习惯性地写 `range(..., M + 1)` 来保证 `i` 能取到 `M`。
* **忽视了偏移量**：本题判断的是 `i` 和 `i + 2`。当我们在循环中使用 `i + k` 时，循环的终点必须相应地**提前停止**，否则会导致访问越界或逻辑溢出。

---

## 💡 知识拓展：双指针与滑动窗口的边界

这种“提前停止”的逻辑在编程中非常常见：
* **查找相邻元素**：如果你在遍历列表 `arr` 比较 `arr[j]` 和 `arr[j+1]`，循环范围通常是 `range(len(arr) - 1)`。
* **计算移动平均**：如果计算长度为 $K$ 的窗口，起始点的遍历范围通常是 `range(Total - K + 1)`。

---

## 📅 避坑指南：边界检查三步法

1.  **确定最大合法值**：本题中 $i$ 带着一个“拖油瓶” $i+2$，所以 $i$ 的最大值必须给 $i+2$ 腾出空间。
2.  **列出不等式**：$i + \text{offset} \le \text{Limit}$。
3.  **转换 range 终点**：$\text{Stop} = \text{Max\_i} + 1$。

---

> **结论**：为了保证较大的孪生素数 $i+2$ 不超过 $M$，较小的 $i$ 最高只能到 $M-2$。在 `range` 函数中，为了取到 $M-2$，终点参数必须设为 **$M-1$**。
