# 🐍 Python 基础知识：幂运算与数字位数的逻辑判定

判断一个正整数是“几位数”，除了常见的 `len(str(N))` 或者 `while N > 0: N //= 10` 之外，还可以利用 **10 的幂次方** 进行区间判定。

---

## 📝 题目回顾

**22、下面的 Python 代码可以用于判断正整数 N 的位数。（ ）**

```python
N = int(input())
i = 1
while True:
    if N % (10 ** i) == N:
        print(f"N是{i}位数")
        break
    i += 1
```

* **A. 正确 (√)**
* B. 错误

**解析**：
* **你的答案**：错误（可能认为取余运算不能直接得出位数）。
* **正确答案**：正确。

---

## 🔍 核心考点深度拆解

### 1. 数学逻辑：取余运算的性质
在数学中，如果 $N < M$，那么 $N \pmod M = N$。
该代码正是利用了这个特性：
* 如果 $N$ 是 **1 位数**（1~9），那么 $N < 10^1$，即 `N % 10 == N` 成立，此时 $i=1$。
* 如果 $N$ 是 **2 位数**（10~99），那么 $N < 10^2$，即 `N % 100 == N` 成立，此时 $i=2$。
* 如果 $N$ 是 **3 位数**（100~999），那么 $N < 10^3$，即 `N % 1000 == N` 成立，此时 $i=3$。



### 2. 代码执行流程（以 N=123 为例）
1.  **第一轮**：$i=1$，计算 `123 % (10**1)` -> `123 % 10 = 3`。
    * `3 != 123`，继续循环，$i$ 变为 2。
2.  **第二轮**：$i=2$，计算 `123 % (10**2)` -> `123 % 100 = 23`。
    * `23 != 123`，继续循环，$i$ 变为 3。
3.  **第三轮**：$i=3$，计算 `123 % (10**3)` -> `123 % 1000 = 123`。
    * **`123 == 123` 成立！** 触发 `break`，输出“N是3位数”。

---

## 💡 知识拓展：多种位数的判定方法

在 Python 开发中，有三种主流方法判断位数，各有优劣：

| 方法 | 代码实现 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| **字符串法** | `len(str(N))` | 最简洁，易读性最高 | 涉及类型转换，大数下略慢 |
| **连续整除法** | `while N: N //= 10` | 纯数学运算，不产生副本 | 会“损毁”原始变量 N |
| **幂运算判定** | `N % (10**i) == N` | 逻辑巧妙，不损毁 N | 涉及大数幂运算，效率一般 |

---

## 📅 避坑指南：符号识别

* **`**` (幂运算)**：注意不要看成 `*`（乘法）。如果代码里是 `10 * i`，逻辑就彻底错了。
* **`%` (取余)**：记住 $N \pmod M = N$ 的前提是 $N < M$。
* **`while True`**：这是一个死循环，如果没有内部的 `break`，程序会崩溃。在这道题中，因为 $i$ 不断增加，$10^i$ 终究会大于 $N$，所以一定会退出。

> **结论**：这道题是一个“数学题披着代码皮”。只要理解了 **“当除数大于被除数时，余数等于被除数本身”** 这个数学常识，就能一眼识破真相。
