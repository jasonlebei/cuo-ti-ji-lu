# 🐍 Python 基础知识：变量命名与内置函数冲突解析

在 Python 编程中，区分“关键字（Keywords）”与“内置函数（Built-in Functions）”是初学者的必修课。

---

## 📝 题目回顾

**问：假设某程序代码中有 `print = 10`，下列有关说法中正确的是？**

- A. 该行代码错误，因为 `print` 是关键字，不能作为变量名称。
- B. 该行代码错误，因为 `print` 是内置函数名，不能作为变量名称。
- C. **该行代码没有错误，print 可以作为变量名称，虽然非常不可取（正确答案）**
- D. 该行代码没有错误，虽然 `print` 是关键字，但也可以作为变量名称。

---

## 🔍 核心考点深度拆解

### 1. 为什么 D 选项是“伪真命题”？（深度解析）
D 选项前半句“没有错误”是正确的，但后半句**“print 是关键字”是彻底错误的**。

* **身份误判**：`print` 在 Python 中是一个 **内置函数**（Built-in Function），而不是 **关键字**（Keyword）。
* **关键字的霸权**：Python 中的关键字（如 `if`, `for`, `def`, `class`）是由编译器硬编码的，具有最高优先级的保留权。你**绝对无法**给关键字赋值。
  `python
  if = 10  # ❌ 抛出 SyntaxError: invalid syntax
  `
* **内置函数的包容**：内置函数本质上是预装在全局命名空间里的“普通变量”。你可以随意给它重新赋值。虽然能跑通，但你会失去原有的打印功能。



---

### 2. 代码执行逻辑：发生了什么？

当你写下 `print = 10` 时，Python 解释器内部发生了以下变化：

1. **查找优先级**：Python 找变量的顺序是 **LEGB**（Local -> Enclosed -> Global -> Built-in）。
2. **遮蔽效应 (Shadowing)**：你创建了一个名为 `print` 的 **Global（全局）** 变量。
3. **功能丢失**：下次你调用 `print()` 时，Python 会先在全局找到你的数字 `10`，而不是去 **Built-in** 层找那个打印函数。

**报错模拟：**
```python
print = 10
print("Hello") 
# 报错信息：TypeError: 'int' object is not callable
# 翻译：你正试图把数字 10 当成函数来调用，这显然是不行的。
```

---

## 💡 总结与避坑

| 类别 | 成员示例 | 能否被赋值为变量？ | 赋值后的后果 |
| :--- | :--- | :--- | :--- |
| **关键字** | `False`, `yield`, `import` | **不能** (强制禁止) | 无法运行，直接报语法错误 |
| **内置函数** | `print`, `len`, `list` | **能** (允许但不推荐) | 原有功能被覆盖，导致后续调用失效 |

---

> **结论**：D 项错在将 `print` 错误地归类为关键字。记住：**关键字是铁律，不可逾越；内置函数是默认配置，可以修改但别乱动。**
