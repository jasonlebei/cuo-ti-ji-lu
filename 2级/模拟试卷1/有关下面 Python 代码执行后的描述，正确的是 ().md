# 🐍 Python 基础知识：变量初始化与循环执行机制

在 Python 中，代码的严谨性体现在每一个变量的使用之前。这道题展示了一个非常隐蔽的运行时错误。

---

## 📝 题目回顾

**问：有关下面 Python 代码执行后的描述，正确的是？**

```python
N = 100
for i in range(N):
    SUM += i
else:
    print(SUM)
```

- A. 程序执行结束后，将输出 1-100 之和
- B. 程序执行结束后，将输出 0-99 之和
- C. 程序执行结束后，将输出 99
- D. **代码执行过程中将报错 (正确答案)**

---

## 🔍 核心考点深度拆解

### 1. 致命伤：未初始化的变量 (NameError)
程序报错的根本原因在于：**`SUM += i`**。

在 Python 中，`SUM += i` 等同于 `SUM = SUM + i`。
* 当循环第一次执行（即 `i = 0`）时，Python 尝试计算 `SUM + 0`。
* 此时，程序发现之前**从未定义**过变量 `SUM`。
* **结果**：Python 会立即抛出 `NameError: name 'SUM' is not defined`。



### 2. range(N) 的范围逻辑
如果我们在循环前加上 `SUM = 0`，那么 B 选项就是正确的。
* `range(100)` 产生的是一个从 **0 到 99** 的序列（左闭右开）。
* 它**不包含** 100。

### 3. else 子句在循环中的作用
很多人看到 `else` 与 `for` 连用会感到奇怪。在 Python 中：
* `for...else` 结构是合法的。
* 当循环**正常结束**（即没有被 `break` 中断）时，`else` 块中的代码会被执行。
* 如果这道题修复了 `SUM` 的初始化问题，它最终会打印出 0-99 的累加和。

---

## 💡 实验对比：如何让它不报错？

如果你想让代码正确运行，必须在循环开始前给 `SUM` 一个“户口”：

```python
N = 100
SUM = 0  # <--- 关键：必须初始化
for i in range(N):
    SUM += i
else:
    print(SUM) # 输出 4950 (0到99之和)
```



---

## 📅 常见命名与语法陷阱总结

| 错误类型 | 触发原因 | 示例 |
| :--- | :--- | :--- |
| **NameError** | 使用了未定义的变量 | `x = y + 1` (若 y 未定义) |
| **SyntaxError** | 违反 Python 语法规则 | `if x = 1:` (应使用 ==) |
| **TypeError** | 对类型不符的对象进行操作 | `'a' + 1` |

---

> **结论**：代码在执行到 `SUM += i` 的第一步时，就会因为找不到 `SUM` 的定义而报错。因此，正确选项是 **D**。
