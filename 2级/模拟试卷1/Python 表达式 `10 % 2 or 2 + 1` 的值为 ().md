# 🐍 Python 基础知识：逻辑运算符与优先级解析

在 Python 中，处理包含算术和逻辑运算的复合表达式时，必须遵循严格的执行顺序。

---

## 📝 题目回顾

**问：Python 表达式 `10 % 2 or 2 + 1` 的值为？**

- A. 0
- B. 2
- C. 1
- D. **3 (正确答案)**

---

## 🔍 核心考点深度拆解

要解出这道题，我们需要按照 Python 解释器的三步逻辑进行分析：

### 1. 优先级划分 (Priority)
Python 会根据运算符优先级表对表达式进行拆解。**算术运算符（%、+）** 的优先级高于 **逻辑运算符（or）**。

因此，原始表达式：
`10 % 2 or 2 + 1`
在后台会被解析为：
`(10 % 2) or (2 + 1)`



### 2. 算术求值 (Arithmetic Calculation)
* **左侧：** `10 % 2` 结果为 `0`（10 除以 2 的余数是 0）。
* **右侧：** `2 + 1` 结果为 `3`。

此时，表达式简化为：`0 or 3`。

### 3. 逻辑短路与返回值 (Logic Short-circuiting)
这是最容易出错的一步。Python 的 `or` 运算遵循以下规则：
* **规则**：`x or y` —— 如果 `x` 为真，则返回 `x`；否则返回 `y`。
* **判定**：在 Python 中，数字 `0` 被视为 `False`，非零数字（如 `3`）被视为 `True`。

由于左侧结果为 `0` (False)，`or` 运算符会继续向右判定，并返回决定表达式最终结果的那个值：`3`。



---

## 💡 深度总结：为什么结果不是 True？

很多初学者会误以为逻辑运算的结果只能是 `True` 或 `False`。

**关键知识点**：Python 的逻辑运算符（`and` 和 `or`）是 **“短路运算符”**，它们返回的是 **决定最终结果的那个操作数本身**，而不是其布尔值。

**对比实验：**
```python
print(0 or 3)    # 输出 3 (左侧为假，返回右侧)
print(5 or 3)    # 输出 5 (左侧为真，直接返回左侧，右侧被“短路”不执行)
print(0 and 3)   # 输出 0 (左侧为假，and 直接判定为假，返回 0)
```

---

## 📅 运算符优先级参考表（由高到低）

| 优先级 | 运算符类型 | 示例 |
| :--- | :--- | :--- |
| **1 (最高)** | 算术运算（幂/乘除取余） | `**`, `*`, `/`, `%` |
| **2** | 算术运算（加减） | `+`, `-` |
| **3** | 比较运算 | `>`, `<`, `==`, `!=` |
| **4** | 逻辑非 | `not` |
| **5** | 逻辑与 | `and` |
| **6 (最低)** | 逻辑或 | `or` |

---


> **最终结论**：根据 `算术 > 逻辑` 的原则，先算 `10%2=0` 和 `2+1=3`。对于 `0 or 3`，由于 0 为假，返回右侧的值，故结果为 **3**。
