# 🐍 Python 基础知识：if 分支结构语法详解

在 Python 中，`if-elif-else` 构成一个完整的逻辑块。理解其“排他性”执行机制是避免逻辑 Bug 的关键。

---

## 📝 题目回顾

**问：下面有关 Python 中 if 语句的说法，错误的是？**

- A. 一个 if 语句可以有 0 个或多个 elif 子句。
- B. 一个 if 语句最多只能有一个 else 子句。
- C. elif 是 Python 关键字，不可用作变量名。
- D. **在一个 if 语句中，满足条件的被控制语句都会被执行（错误说法，故选 D）**

---

## 🔍 核心考点深度拆解

### 1. 为什么 D 选项是错误的？（执行机制）
在一个完整的 `if-elif-else` 结构中，Python 遵循 **“首位命中即停止”** 的原则：
* 系统会自上而下检查条件。
* 一旦某个条件满足（为 True），对应的代码块会被执行。
* **关键点**：执行完该块后，Python 会**直接跳出**整个 if 结构，不再检查后续的 elif 或 else。



**对比演示：**
```python
score = 95
if score > 60:
    print("及格了")
elif score > 90:
    print("优秀")
# 结果只打印 "及格了"，虽然 95 也大于 90，但第二个语句被跳过了。
```

### 2. A 和 B 选项（结构完整性）
* **elif 的灵活性**：你可以根据需要写任意多个判断条件，也可以一个都不写（只用 if 和 else）。
* **else 的唯一性**：`else` 代表“所有条件都不满足时的兜底方案”，因此在一个 if 块中最多只能有一个。

### 3. C 选项（关键字判定）
* `elif`、`if`、`else` 都是 Python 的**保留关键字**。
* 正如我们之前讨论过的，关键字是语言的骨架，绝对不能赋值作为变量名，否则会报 `SyntaxError`。

---

## 💡 易错点拨：多个 if vs if-elif

如果你希望“所有满足条件的语句都被执行”，你需要使用**多个独立的 if 语句**，而不是一个 if 结构：

| 结构类型 | 代码逻辑 | 执行效果 |
| :--- | :--- | :--- |
| **if-elif 链** | 互斥关系 | 只要找到一个满足的，剩下全不看 |
| **多个 if** | 独立关系 | 每一个 if 都会被判断，满足几个执行几个 |



---

## 📅 分支语句语法规则表

| 组成部分 | 出现次数 | 顺序要求 |
| :--- | :--- | :--- |
| **if** | 必须有 1 个 | 必须在最开头 |
| **elif** | 0 个或多个 | 必须在 if 之后，else 之前 |
| **else** | 0 个或 1 个 | 必须在最后面 |

---

> **结论**：在一个 if 分支块内，满足条件的语句**只有第一个**会被执行，而不是“都会”执行。
