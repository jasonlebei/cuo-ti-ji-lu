# 🐍 Python 基础知识：嵌套循环执行次数计算

在 Python 中，嵌套循环的总执行次数等于 **外层循环次数 × 每次外层循环时内层执行的次数**。

---

## 📝 题目回顾

**问：以下程序输出 "OK" 的次数为？**

```python
for i in range(8, 2, -2):
    for j in range(i):
        print("ok")
```

- A. 0
- B. 12
- C. **18 (正确答案)**
- D. 20

---

## 🔍 核心考点深度拆解

我们要解出这道题，需要先解开 `range()` 函数的三个参数：`range(start, stop, step)`。

### 1. 分析外层循环 `range(8, 2, -2)`
* **start = 8**: 从 8 开始。
* **stop = 2**: 到 2 停止（注意：**不包含 2**）。
* **step = -2**: 每次减 2。



**外层变量 `i` 的取值依次为：**
1. 第一轮：`i = 8`
2. 第二轮：`i = 6`
3. 第三轮：`i = 4`
(下一轮是 2，因为不包含 stop 值，所以循环结束)

### 2. 分析内层循环 `for j in range(i)`
内层循环的次数直接取决于当前的 `i` 值。

| 外层 i 的值 | 内层执行次数 `range(i)` | 打印 "OK" 的数量 |
| :--- | :--- | :--- |
| **8** | `range(8)` 即 0 到 7 | 8 次 |
| **6** | `range(6)` 即 0 到 5 | 6 次 |
| **4** | `range(4)` 即 0 到 3 | 4 次 |



### 3. 计算总和
将每一轮内层执行的次数相加：
**8 + 6 + 4 = 18**

---

## 💡 易错点拨：为什么不是 20 或 12？

* **为什么不选 20？** 很多人忘记了 `range(start, stop)` 是**左闭右开**的。如果包含了 `i=2` 那一轮，总数就是 `18 + 2 = 20`。但在 Python 中，`stop` 位的值永远取不到。
* **步长正负号**：如果 `step` 是负数，`start` 必须大于 `stop` 才能进入循环；反之则一次都不执行（这就是你答案选 0 的原因，可能当时误判了循环方向）。

---

## 📅 嵌套循环逻辑表

```python
for i in range(8, 2, -2): # 产生 8, 6, 4
    for j in range(i):    # 产生 i 次循环
        print("ok")
```

| 轮次 | i 的值 | 内部循环 j 的范围 | 计数贡献 |
| :--- | :--- | :--- | :--- |
| 1 | 8 | 0, 1, 2, 3, 4, 5, 6, 7 | 8 |
| 2 | 6 | 0, 1, 2, 3, 4, 5 | 6 |
| 3 | 4 | 0, 1, 2, 3 | 4 |
| **总计** | | | **18** |

---

> **结论**：外层循环 3 次，对应内层分别执行 8, 6, 4 次，累加结果为 **18**。
